# 도라에몽 · 연구 서재 AI (v3, 나만 쓰는 플랫폼)

내 구글 드라이브의 자료를 AI가 읽고 분류해서 **도서관 책장처럼** 보여 줍니다.
AI 정리(보고서 · 주해 · 디지털 신학 등)는 **내 서재 안의 자료만** 근거로 씁니다.
올린 파일은 구글 드라이브에 저장되고 분류 폴더로 정리됩니다.

## 화면 (아래 메뉴 3개)

| 메뉴 | 하는 일 |
|---|---|
| **내 서재** | 책장 보기 — 분류 · 주제 · 성격(주석 · 신학서 · 설교 등) · 성경 · 저자 · 수준 · 파일 · 폴더 · 최근. AI가 책마다 핵심 주장 · 요약 · 주제 · 성격 · 수준을 분석해 둡니다. 책장을 누르면 그 자료가 모이고, 자료를 누르면 요약 · 주제 · 위치와 "구글 드라이브에서 열기". 위 검색칸은 제목 · 저자 · 주제, "본문에서 찾기"는 내용까지. "＋ 올리기" 또는 끌어 놓기 |
| **AI 정리** | 지침 고르기 → 본문이나 주제 + 내 생각 → 만들기. 찾을 범위는 서재 전체 · 책장 하나 · 자료 하나. 근거마다 책 · 쪽 · 드라이브 위치 · 원본 링크 |
| **보관함** | 만든 자료 다시 열기 · Word · PDF |

설정: 나의 연구 철학, 자동 정리, 분류 목록, 서재 관리(내 드라이브 전체 · 폴더 연결 · 색인 상태).

## 새로 만들기 (플랫폼은 따로, 로그인 · AI 중계는 Overflow와 같이)

따로인 것: 깃허브 저장소(주소) · 드라이브 폴더 "도라에몽 서재" · 기기 저장. 서재 · 지침 · 결과물이 Overflow와 섞이지 않습니다.
같이 쓰는 것: 구글 로그인 열쇠(OAuth 클라이언트)와 AI 중계(Apps Script). 그래서 새 결제나 새 AI 키가 필요 없습니다.
AI 하루 사용 한도(OWNER_LIMIT)만 Overflow와 함께 씁니다. config.js에는 이미 두 값이 들어 있습니다.

아래 `<아이디>`는 새로 쓸 깃허브 아이디(개인 계정)입니다. 주소는 `https://<아이디>.github.io/doraemon/`.

1. **깃허브 저장소**: github.com(개인 계정) → ＋ → New repository → 이름 `doraemon` → Public → Create
   → Add file → Upload files → `index.html · config.js · manifest.json · pdf.min.mjs · pdf.worker.min.mjs · icon-180.png · icon-192.png · icon-512.png` → Commit
2. **Pages 켜기**: 저장소 Settings → Pages → Branch: main / (root) → Save → 1~2분 뒤 주소가 열림
3. **구글 로그인에 새 주소 알려 주기**: Google Cloud 콘솔 → Overflow 프로젝트 → API 및 서비스(Google 인증 플랫폼) → 클라이언트 → Overflow에서 쓰는 웹 클라이언트
   - 승인된 자바스크립트 원본에 `https://<아이디>.github.io` 추가
   - 승인된 리디렉션 URI에 `https://<아이디>.github.io/doraemon/` 추가 (끝의 / 까지)
   - 저장 (반영까지 몇 분 걸릴 수 있음)
4. **확인**: 주소 열기 → 구글 로그인 → 설정 → AI 연결 → "연결 확인"이 ✓
5. **패드 · 휴대폰**: 사파리로 주소 → 공유 → 홈 화면에 추가
6. **서재 채우기**: 내 서재 → "내 드라이브의 PDF 전부 정리하기" (또는 설정 → 서재 관리에서 폴더만 지정)

AI 중계 Apps Script는 고칠 것이 없습니다(같은 클라이언트의 로그인이라 그대로 통과).

### 잘 안 될 때
- "redirect_uri_mismatch": 3번의 리디렉션 URI가 주소와 글자 하나까지 같은지(끝의 / 포함)
- AI 연결 확인에서 "로그인을 확인하지 못했습니다": config.js의 clientId가 Overflow와 같은지
- 화면이 예전 그대로: 사파리 새로고침, 또는 홈 화면 아이콘을 지웠다가 다시 추가

## 드라이브 정리 방식

- 내 드라이브의 원래 파일: 읽기만 합니다. 옮기거나 이름을 바꾸지 않습니다.
- 여기서 올린 파일: `도라에몽 서재 / 올린 자료 / <분류>` 폴더로 옮기고 "[저자] 제목"으로 이름 정리.
- 색인 · 지침 · 결과물: `도라에몽 서재 / 색인 · 지침 · 결과물`.

## 읽는 파일

PDF(쪽) · 워드(쪽) · 한글 HWP/HWPX · PPT(슬라이드 + 발표자 노트) · 엑셀 · 사진(글자 인식) · 텍스트 · 영상/음성.
영상 · 음성은 같은 폴더에 같은 이름의 자막(.srt · .vtt · .smi)이 있으면 시각별로 색인합니다.
자막 없이 내용까지 하려면 아래 받아쓰기 중계(선택)를 연결하세요.

## 영상 받아쓰기 중계 (선택)

1. https://aistudio.google.com 에서 Gemini API 키 만들기
2. https://script.google.com → 새 프로젝트 → `media-relay.gs` 붙여 넣기 → 저장
3. 프로젝트 설정 → 스크립트 속성: `GEMINI_API_KEY`, `OWNER_EMAIL`(leehyesung516@gmail.com)
4. 배포 → 새 배포 → 웹 앱 → 실행: 나 · 액세스: 모든 사용자 → URL 복사 → config.js `mediaUrl`에 넣고 다시 올리기
(이 중계만 새 Apps Script 프로젝트로 만듭니다. Gemini는 쓴 만큼 요금이고 무료 구간이 있습니다)

Gemini 무료 등급은 보낸 내용이 서비스 개선에 쓰일 수 있습니다. 민감한 영상이 많으면 유료 등급을 쓰세요.

## 이름 바꾸기

config.js의 `appName`, manifest.json의 `name · short_name`, index.html 맨 위 `<title>`과 `apple-mobile-web-app-title`.
"도라에몽"은 다른 회사의 상표 · 캐릭터 이름이라 혼자 쓰는 동안만 권합니다. 다른 사람과 나누게 되면 이름을 바꾸고, 로고에 캐릭터 그림은 쓰지 마세요.

PDF 글 뽑기와 쪽 보기에 pdf.js(Mozilla, Apache-2.0)를 씁니다.
